# Trazabilidad JIRA — AllAtYou Taller

Directorio para registrar tickets JIRA (`TALLER-[NUM]`) cuando se requiera trazabilidad formal.

## Reglas Clave:
1. **Formato ultra-compacto:** Utilizar [`docs/jira/JIRA_ISSUE_TEMPLATE.md`](./JIRA_ISSUE_TEMPLATE.md) (máximo 15-20 líneas).
2. **Sin ceremonia en tareas iterativas:** Fixes rápidos o iteraciones UI no requieren crear tickets markdown previos, se implementan directamente.
3. **Commit prefix:** `[TALLER-XXX] <tipo>(<alcance>): <descripción>`.
